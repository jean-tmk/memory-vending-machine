# Memory Vending Machine

Insert a word, tune the age and distortion, and receive an archival receipt for a memory that may never have happened.

The project is Python-led: `generate.py` contains the catalogue, deterministic memory compositor, distortion rules, receipt metadata, archive behavior, and browser-runtime template. Run it to rebuild `runtime.js` and `memory-data.json` for the static GitHub Pages deployment.

```bash
python generate.py
```
